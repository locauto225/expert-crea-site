# Site web + WhatsApp : comment recevoir plus de messages et d’appels

En Côte d’Ivoire, beaucoup de clients ne remplissent pas toujours un long formulaire.  
Ils veulent **appeler** ou **écrire sur WhatsApp** rapidement.

Donc l’objectif d’un bon site, ce n’est pas seulement “être joli”, c’est surtout **faciliter le contact**.

## 1) WhatsApp doit être visible partout
Si le client doit chercher le contact, il abandonne.

À mettre :
- un bouton WhatsApp dans le header
- un bouton WhatsApp flottant (sur mobile surtout)
- un rappel WhatsApp en bas de page

## 2) Le bouton doit ouvrir une discussion directe
Le lien le plus simple :

- `https://wa.me/225XXXXXXXXX`

Tu peux aussi pré-remplir un message (très efficace) :

- `https://wa.me/225XXXXXXXXX?text=Bonjour%20je%20veux%20un%20devis`

## 3) Mets aussi un bouton “Appeler”
Même si WhatsApp marche bien, il y a des clients qui préfèrent appeler directement.

Sur mobile, un bouton “Appeler” bien placé = plus de contacts.

## 4) Mets un message clair juste avant les boutons
Exemples simples (qui parlent aux gens) :
- “Besoin d’un devis rapide ? Écris-nous sur WhatsApp.”
- “Une question ? Appelle-nous maintenant.”
- “On répond vite (WhatsApp / appel).”

Ça rassure et ça pousse à l’action.

## 5) Ne mets pas 10 actions différentes
Trop de choix = la personne ne fait rien.

Sur la page, garde 2 actions principales :
- WhatsApp
- Appeler
(Le formulaire en troisième option, si tu veux.)

## 6) Une page Contact ultra simple
Ta page contact doit contenir :
- WhatsApp + Appel (visible dès l’arrivée)
- horaires (si tu veux)
- email (optionnel)
- adresse / zone d’intervention (si utile)

Pas besoin de texte long.

## 7) Mets des “raccourcis” sur les pages services
Sur chaque page service :
- un bloc “Demander un devis” (WhatsApp + appel)
- 2–3 infos clés (prix ou fourchette, délai, ce que tu livres)

Le client lit et il contacte.

## 8) Répondre vite (sinon tu perds le prospect)
Ce point est simple mais réel : si tu réponds 24h après, le client est déjà parti ailleurs.

Même une réponse courte :
- “Bonjour, merci. Quel est votre besoin ?”
- “Vous êtes dans quel secteur ?”
- “Vous souhaitez un site vitrine ou un site avec paiement ?”

## 9) Bonus : donne un “message type”
Ça aide les gens à écrire plus facilement.

Exemple :
“Bonjour, je suis [nom]. J’ai une entreprise de [activité]. Je veux un devis pour [service].”

Tu peux l’ajouter dans le lien WhatsApp pré-rempli.

## Checklist rapide (spécial CI)
- [ ] Bouton WhatsApp visible (header + bouton flottant)
- [ ] Bouton Appeler visible (mobile)
- [ ] Message rassurant avant les boutons
- [ ] Contact simple et rapide
- [ ] CTA WhatsApp sur chaque page service
- [ ] Réponse rapide aux messages
