# Checklist avant de mettre ton site en ligne (SEO, vitesse, WhatsApp, sécurité)

Mettre un site en ligne, ce n’est pas juste “cliquer publier”.  
Avant de partager ton lien, voici une checklist simple pour éviter les erreurs et être prêt pour recevoir des demandes.

---

## 1) Contact : WhatsApp + Appel (priorité en CI)
- [ ] Bouton WhatsApp visible (header + bouton flottant si possible)
- [ ] Bouton “Appeler” visible sur mobile
- [ ] Page Contact claire (WhatsApp, téléphone, email)
- [ ] Les liens fonctionnent (wa.me, tel:)

✅ Test : ouvre le site sur téléphone et essaye d’écrire sur WhatsApp en 1 clic.

---

## 2) Pages essentielles
- [ ] Accueil
- [ ] Services (et idéalement 1 page par service)
- [ ] Réalisations / exemples (même peu)
- [ ] À propos (qui êtes-vous)
- [ ] Contact

---

## 3) Mobile : lisible et confortable
- [ ] Textes lisibles (pas trop petits)
- [ ] Boutons assez gros
- [ ] Pas de décalage / éléments qui débordent
- [ ] Navigation simple

✅ La majorité des visiteurs sont sur mobile → c’est obligatoire.

---

## 4) Vitesse : pas de site lent
- [ ] Images optimisées (pas des fichiers énormes)
- [ ] Pas trop d’animations lourdes
- [ ] Pages qui chargent vite sur 4G

✅ Un site lent = des clients perdus.

---

## 5) SEO de base (être trouvé sur Google)
- [ ] Chaque page a un bon titre (clair)
- [ ] Chaque page a une description
- [ ] URLs propres (ex: /services/creation-site-web)
- [ ] Un sitemap est présent
- [ ] Robots.txt OK

✅ Le SEO de base te permet déjà d’être visible.

---

## 6) Réseaux sociaux / partage (Open Graph)
Quand quelqu’un partage ton lien sur WhatsApp / Facebook :
- [ ] Une image s’affiche
- [ ] Le titre est correct
- [ ] La description est correcte

✅ Sinon ça fait “pas pro” et ça réduit les clics.

---

## 7) Sécurité et propreté
- [ ] HTTPS actif (SSL)
- [ ] Aucune page en erreur (404)
- [ ] Aucun lien cassé
- [ ] Pas de texte “placeholder” (XX XX, lorem ipsum…)

---

## 8) Tracking simple (optionnel mais utile)
Si tu veux mesurer :
- [ ] Google Analytics (trafic)
- [ ] Événements : clic WhatsApp, clic Appeler, formulaire envoyé

✅ Ça te permet de savoir ce qui ramène des demandes.

---

## 9) Nom de domaine (si tu en as un)
- [ ] Domaine pointé correctement
- [ ] Redirection www ou non-www (choisir un seul)
- [ ] Emails pro configurés (contact@…)

---

## Mini test final (à faire en 10 minutes)
1) Test sur téléphone (WhatsApp / appel / navigation)  
2) Test sur ordinateur (lecture, sections, liens)  
3) Partage le lien dans WhatsApp → vérifie l’aperçu  
4) Clique tous les CTA importants  

---
