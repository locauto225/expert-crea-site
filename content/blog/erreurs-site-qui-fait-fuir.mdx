# 7 erreurs sur un site web qui font fuir les clients

Un site peut être “joli”, mais si le client ne comprend pas vite, ou s’il ne peut pas te contacter facilement, il part.  
Voici les erreurs les plus fréquentes (et comment les corriger simplement).

## 1) On ne comprend pas ce que tu fais en 5 secondes
Erreur : un slogan vague, des phrases trop générales, pas de service clair.  
✅ Solution : une phrase simple dès le début :
- “Création de site web + visibilité Google”
- “Identité visuelle + supports de communication”
- “Outils de gestion / extranet”

## 2) Aucun bouton WhatsApp / Appel visible
Erreur : contact caché dans un menu ou en bas de page.  
✅ Solution : WhatsApp + Appel visibles :
- dans le header
- en bouton flottant (mobile)
- sur chaque page service

## 3) Trop de texte, pas assez de structure
Erreur : gros paragraphes, personne ne lit.  
✅ Solution : titres clairs (H2), listes courtes, sections simples.

## 4) Pas de preuves (réalisations, avis, photos)
Erreur : le client ne sait pas si tu es sérieux.  
✅ Solution : même avec peu :
- 2–3 réalisations
- photos réelles
- témoignages (même courts)
- logos de clients (si tu peux)

## 5) Site lent ou mal adapté au téléphone
Erreur : sur mobile, ça rame, textes trop petits, boutons difficiles.  
✅ Solution :
- images optimisées
- pages légères
- CTA gros et cliquables

## 6) Pages “Services” trop vagues (tout mélangé)
Erreur : une seule page “services” où tout est mélangé.  
✅ Solution : 1 service = 1 page :
- /services/creation-site-web
- /services/referencement-seo
Ça aide le client et Google.

## 7) Design “trop chargé” ou pas pro
Erreur : trop de couleurs, trop d’effets, trop d’animations, ça fait “pas sérieux”.  
✅ Solution : un style simple :
- 2 couleurs principales
- beaucoup d’espace
- textes lisibles
- hiérarchie claire

---

## Mini checklist (à vérifier sur ton site)
- [ ] En 5 secondes, on comprend ton service
- [ ] WhatsApp + Appel visibles partout
- [ ] Preuves (réalisations/avis/photos)
- [ ] Mobile fluide et rapide
- [ ] Pages services séparées
- [ ] Design simple et pro
